Diagnóstico de DNS Linux

Objetivo

Documentar consultas e verificações relacionadas ao DNS.

Comandos utilizados

nslookup google.com

getent hosts google.com

cat /etc/resolv.conf

Finalidade

- "nslookup": consulta informações DNS.
- "getent hosts": consulta a resolução de nomes.
- "/etc/resolv.conf": apresenta configurações de resolução DNS.

Ambiente

Ubuntu Linux utilizando WSL 2.

Importância

O DNS permite localizar servidores por meio de nomes de domínio.

Status
