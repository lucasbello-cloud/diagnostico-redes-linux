Interfaces de Rede Linux

Objetivo

Identificar as interfaces de rede disponíveis no Ubuntu.

Comandos utilizados

ip addr
ip link
hostname -I

Finalidade

- "ip addr": consulta endereços IP e interfaces.
- "ip link": apresenta informações das interfaces.
- "hostname -I": mostra os endereços IP do sistema.

Ambiente

Ubuntu Linux utilizando WSL 2.

Status

Documentação de comandos para diagnóstico de rede.
