Diagnóstico e Monitoramento de Redes Linux

Objetivo

Documentar procedimentos e comandos de diagnóstico e monitoramento de redes utilizando Linux.

Ambiente

- Ubuntu Linux
- WSL 2
- Terminal Linux

Conteúdo do projeto

1. Interfaces de rede: identificação de interfaces e endereços IP.
2. Conectividade: testes de comunicação e consulta de rotas.
3. DNS: resolução de nomes e consultas DNS.
4. Conexões: consulta de conexões e portas de rede.
5. Diagnóstico: procedimentos para identificar possíveis problemas.
6. Comandos Linux: referência dos principais comandos utilizados.

Tecnologias e ferramentas

- Linux
- Ubuntu
- WSL 2
- Comandos de rede

Competências desenvolvidas

- Administração Linux
- Redes de computadores
- Diagnóstico de conectividade
- Monitoramento de rede
- Infraestrutura de TI

Status

<badge>Documentação organizada</badge>

Projeto de estudo desenvolvido em ambiente Ubuntu com WSL 2. Os comandos estão documentados para prática e consulta; a documentação não representa uma implantação de infraestrutura de rede real.
