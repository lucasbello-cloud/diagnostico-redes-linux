Monitoramento de Conexões Linux

Objetivo

Documentar comandos para consultar conexões e portas de rede.

Comandos utilizados

ss -tuln

ss -tun

ip route

Finalidade

- "ss -tuln": consulta portas TCP e UDP.
- "ss -tun": apresenta conexões TCP e UDP.
- "ip route": consulta as rotas de rede.

Ambiente

Ubuntu Linux utilizando WSL 2.

Importância

O monitoramento de conexões ajuda a analisar a comunicação de rede do sistema.

Status

Documentação do projeto.
