Comandos Linux para Diagnóstico de Redes

Comando| Função
"ip addr"| Consultar endereços IP
"ip link"| Consultar interfaces
"hostname -I"| Mostrar IPs
"ip route"| Consultar rotas
"ping"| Testar conectividade
"nslookup"| Consultar DNS
"getent hosts"| Resolver nomes
"ss -tuln"| Consultar portas
"curl -I"| Verificar resposta HTTP

Ambiente

Ubuntu Linux com WSL 2.

Objetivo

Reunir comandos utilizados em atividades de diagnóstico e monitoramento de redes.
